## 概述

KBManager 是一个**知识库文件标签管理工具**，用于对 Markdown 知识库文件进行标签化管理，并集成 Git 版本控制操作。核心功能：

- 📁 树形浏览知识库文件，批量管理标签
- 🔍 按标签模糊搜索，快速定位文件
- 🏷️ 标签自动补全，按文件量排序，支持模糊过滤
- 🔧 Git 集成：Clone、Add、Commit、Push（SSH）
- 🎨 统一的主题配色，支持通过 `theme.json` 自定义

## 快速开始

### 1. 启动应用

双击 `KBManager.GUI.exe`，应用窗口居中显示。

### 2. 首次配置

启动后**首先进入设置页面**（左侧导航 → ⚙ 设置），填写以下必填项：

| 字段 | 说明 | 示例 |
|------|------|------|
| Git 用户名 | 用于 Git 提交记录 | `Zhang San` |
| Git 邮箱 | 用于 Git 提交记录 | `zhangsan@example.com` |
| 仓库目录 | 本地知识库的根目录 | `D:\MyKB` |

远程地址（HTTPS / SSH）可选填，用于 Clone 和 Push。

点击 **💾 保存配置** 完成设置。

### 3. 初始化数据库

首次使用时，需要在仓库目录下创建知识库数据库。可通过以下任一方式：

- 在 **文件管理** 页面点击 **🔄 同步文件**
- 在命令行中运行 `KBManager.CLI initdb`

## 设置页面

路径：左侧导航 → **⚙ 设置**

### Git 用户信息

- **用户名**：Git 提交时使用的作者名（必填）
- **邮箱**：Git 提交时使用的邮箱地址（必填）

### 远程仓库

- **HTTPS 地址**：用于 Clone 操作的 HTTPS 远程地址
- **SSH 地址**：用于 Push 操作的 SSH 远程地址（如 `git@github.com:user/repo.git`）

### 本地目录

- **仓库目录**：知识库 Markdown 文件所在的本地根目录（必填）
- 点击 **📂 浏览** 按钮可通过文件夹选择对话框选取

### 操作按钮

- **💾 保存配置**：保存所有设置到配置文件
- 页面激活时自动加载当前配置

```
└──────────────────────────┴───────────────────────┘
```

### 工具栏

| 按钮 | 功能 | 说明 |
|------|------|------|
| 🔄 同步文件 | 扫描仓库目录 | 扫描仓库目录中的 .md 文件，同步到数据库 |
| 📝 打开编辑 | 打开选中文件 | 用系统默认编辑器打开选中的 Markdown 文件 |
| 🗑 移除记录 | 移除文件记录 | 从数据库中移除文件记录（不删除实际文件） |

### 文件树

- 以**树形目录结构**展示所有已索引的 Markdown 文件
- 每个文件名后面显示 `(N)` 表示该文件当前拥有的标签数量
- 目录节点以 📁 图标标识，文件节点以 📄 图标标识
- 点击文件节点即可选中，右侧面板显示其标签信息

### 标签编辑面板

选中一个文件后，右侧面板显示：

#### 现有标签
- 以**芯片样式**展示当前文件的所有标签
- 点击标签右侧的 **✕** 按钮可快速移除该标签

#### 添加新标签
- 在输入框中输入标签名称
- 输入时自动弹出**建议列表**：
  - 显示所有已存在的标签（按文件数量降序排列）
  - 实时模糊过滤，输入即搜索
  - 仅显示**当前文件尚未拥有**的标签
- **双击建议项**或**按回车键**：直接添加该标签并清空输入框
- 也可以点击 **➕** 按钮手动添加

> 💡 **提示**：建议列表显示每个标签后面跟着的文件数量，如 `python (15个文件)`，帮助你了解标签的使用频率。

## Git 操作页面

路径：左侧导航 → **📦 Git 操作**

集成 Git 基本操作，无需离开应用即可管理版本控制。

### 界面概览

```
┌──────────────────────────────────────────────────┐
│  📦 Git 操作                                       │
│  管理 Git 仓库：克隆、暂存、提交、推送                 │
├──────────────────────────────────────────────────┤
│  [📥 Clone] [📌 Main Add] [📌 Sub Add] [📋 查看配置] │
├──────────────────────────────────────────────────┤
│  提交操作                                          │
│  [输入提交信息....................................] │
│  [💾 Main Commit] [💾 Sub Commit] [🚀 Push (SSH)]  │
│  ┌──────────────────────────────────────────────┐ │
│  │  操作日志将在此显示...                          │ │
│  │  [09:15:32] 开始克隆仓库...                     │ │
│  │  [09:15:35] 克隆成功 ✓                         │ │
│  └──────────────────────────────────────────────┘ │
│  💡 提示: Push 操作使用 SSH 密钥                     │
└──────────────────────────────────────────────────┘
```

### 操作按钮

| 按钮 | 功能 | 说明 |
|------|------|------|
| 📥 Clone | 克隆仓库 | 使用 HTTPS 地址克隆远程仓库到本地目录 |
| 📌 Main Add | 主仓库暂存 | 执行 `git add .` 暂存主仓库所有变更 |
| 📌 Sub Add | 子模块暂存 | 暂存所有子模块的变更 |
| 📋 查看配置 | 显示当前 Git 配置 | 在日志区显示用户名、邮箱、远程地址等信息 |

### 提交操作

1. 在**提交信息**输入框中填写本次提交的描述
2. 点击 **💾 Main Commit** 提交主仓库变更
3. 或点击 **💾 Sub Commit** 提交子模块变更
4. 提交成功后输入框自动清空

### Push 推送

- 点击 **🚀 Push (SSH)** 将本地提交推送到远程仓库
- 推送前会弹出确认对话框，显示目标 SSH 地址
- 自动检测 `~/.ssh/id_ed25519` 或 `id_rsa` 密钥

### 日志输出

- 所有 Git 操作的结果会实时显示在日志区域
- 包含时间戳、操作类型和成功/失败状态
- 自动截断保留最近 8000 字符

## 主题自定义

KBManager 支持通过 `theme.json` 文件自定义全局配色。

### 文件位置

将 `theme.json` 放在 `KBManager.GUI.exe` 同级目录下。首次运行时会自动生成一份示例文件。

### 自定义方式

编辑 `theme.json`，修改颜色值（支持标准 HEX 格式如 `#FF5733`），共 37 个语义化颜色标记，分为以下类别：

| 类别 | 标记示例 | 说明 |
|------|---------|------|
| **品牌色** | `PrimaryColor`, `PrimaryHoverColor` | 主色调，用于导航高亮、链接等 |
| **危险色** | `DangerColor`, `DangerHoverColor` | 删除、危险操作按钮 |
| **次要色** | `SecondaryColor`, `SecondaryHoverColor` | 次要按钮、辅助元素 |
| **文字色** | `TextPrimaryColor`, `TextSecondaryColor`, `TextMutedColor` | 各级文字颜色 |
| **背景色** | `BackgroundDefaultColor`, `BackgroundSidebarColor`, `BackgroundSectionColor` | 页面和面板背景 |
| **边框色** | `BorderDefaultColor`, `BorderInputColor`, `BorderFocusColor` | 边框和输入框 |
| **特殊色** | `TitleBarBackgroundColor`, `ScrollBarThumbColor`, `WatermarkColor` | 标题栏、滚动条、占位符 |

修改后重新启动应用即可生效。文件支持 JSON 注释（`//`）。

## 常见问题

### Q: 为什么按钮都是灰色的点不了？

A: 请先到 **⚙ 设置** 页面配置仓库目录并保存。

### Q: 搜索文件没有结果显示？

A: 请先在 **📁 文件管理** 页面点击 **🔄 同步文件**，确保文件已索引到数据库。

### Q: 标签建议列表为空？

A: 需要先为一些文件添加标签，标签列表会从数据库中自动汇总。

### Q: Push 失败？

A: 请确认：
1. 设置中已配置 SSH 远程地址
2. `~/.ssh/` 目录下存在 `id_ed25519` 或 `id_rsa` 密钥
3. 已添加 SSH 公钥到远程仓库

### Q: 应用闪退怎么办？

A: 桌面会自动生成 `KBManager_crash.log` 崩溃日志文件，可据此排查问题。

### Q: 如何更换配色？

A: 编辑应用目录下的 `theme.json` 文件，修改颜色值后重启即可。详见 [主题自定义](#主题自定义)。
